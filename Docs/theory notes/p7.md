# Part B: Theory and rules

**New rules from these pages**

1. **Entry types (p38-39):**
   - **ET1:** the zone has trade score 7. Place a resting limit order at the proximal line. This is a "set and forget" trade.
   - **ET2:** trade score 6. Candle 1 closes inside the zone and candle 2 opens inside the zone. Buy at candle 2's open.
   - **ET3:** trade score 6. Candle 1 closes inside the zone and candle 2 leaves the zone upward. Enter after the zone is left. It is the safest entry because it gives extra confirmation, so "ET3 is better than ET2".
   - **Gap filter:** skip ET2 when there is a very large gap up or down. ✱
   - **Selection:** a strong zone gets ET1. A weaker zone uses ET2 or ET3. ✱
   - **Waiting limit:** wait 2-3 candles at most for confirmation. ✱
2. **Authenticity (p40), execution TF only:**
   - A zone that formed because of a previous same-direction zone (DZ2 formed due to DZ1) is non authentic. Default: no trade.
   - Authenticity is checked on the left side (what came before). Confirmation is on the right side (what comes after).
3. **Exceptions that make a non authentic zone tradable (p41):**
   - a. The legout is explosive, for example a range breakout with new buying.
   - b. The zone closes above the previous demand zone's reaction. ✱
   - c. Trend, sector and market all agree. Then even trade score 6 works. ✱
4. **Trading styles (p42-43):**

| Style | Trades | Accuracy / SL | Gap risk | Notes |

| HIT | many | low accuracy, SL 60-70% on tiny zones | none (intraday) | margin available; watch few stocks |
| DIT | slightly fewer | low accuracy, SL a bit less than HIT | none | some margin + leverage |
| WIT | fewer | higher win % | about 10% of cases | take at least 100 trades |
| MIT | fewest | accuracy 80-90%, target up to 1:5, SL rare | handles long-term volatility | take at least 100 trades |

   - Don't do HIT/DIT for 6-8 months (or 2-3 ✱, see my note below).

def pick_entry_type(z):
    s = trade_score(z)
    if s >= 7:   return "ET1"          # limit order at proximal
    if s >= 6:   return "ET3"          # default for weaker zones; ET2 allowed by config
    return None                        # below min score: no trade (confirm with teacher)

MAX_GAP_ATR = 1.0   # "very large gap" threshold, config ✱
MAX_WAIT_CANDLES = 3

def entry_signal(z, candles, etype, atr):
    """candles: last closed candles, c[-1] = latest. Demand-zone (BUY) version."""
    inz = lambda p: z.low <= p <= z.high
    if etype == "ET1":
        return ("LIMIT", z.prox)                       # set and forget
    c1, c2 = candles[-2], candles[-1]
    if etype == "ET2":
        gap = abs(c2.open - c1.close)
        if inz(c1.close) and inz(c2.open) and gap <= MAX_GAP_ATR * atr:
            return ("MARKET_AT_OPEN", c2.open)         # buy as candle 2 opens
    if etype == "ET3":
        if inz(c1.close) and c2.close > z.high:        # candle 2 leaves zone upside
            return ("MARKET", c2.close)
    return None
# For ET3, cancel the setup if no exit from the zone within MAX_WAIT_CANDLES.

```python
def is_authentic(z, prior_zones):
    """Non-authentic if z formed because of an earlier same-type zone (p40)."""
    for p in prior_zones:
        if p.type == z.type and p.index < z.index and formed_from(z, p):
            return False
    return True

def formed_from(z, p):
    # ✱ heuristic, to confirm with teacher: z's legin starts from p's reaction move,
    # i.e. price rallied off p and z is only the pullback in that same swing
    return z.legin_start_index >= p.exit_index and no_new_structure_between(p, z)

def tradable(z, prior_zones, ctx):
    if is_authentic(z, prior_zones):
        return True
    if z.legout_explosive or z.legout_range_breakout:         # p41 exception a
        return True
    p = nearest_prior_same_type(z, prior_zones)
    if p and z.close_above_prior_reaction(p):                 # p41 exception b ✱
        return True
    if ctx.trend_ok and ctx.sector_ok and ctx.market_ok and trade_score(z) >= 6:
        return True                                           # p41 exception c ✱
    return False
```

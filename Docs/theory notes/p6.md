# Part B: Theory and rules

**New rules from these pages**

1. **Trade score (p35)**, computed on the execution TF, maximum 7:
   - Freshness: fresh = 3, tested once = 1.5, tested twice or more = 0.
   - Strength: 2 exciting legouts = 2, 1 legout with a gap = 2, 1 legout without a gap = 1.
   - Time at base: 1-3 candles = 2, 4-5 = 1, more than 5 = 0.
   - No-base zone: check the lower TF; otherwise give a flat 2 for the time parameter. ✱
   - Among competing zones, pick the highest score.
2. **Location backs execution (p36).** Every execution zone should have an HTF location zone behind it.
3. **Overlap (p36).** The closer the execution zone is to the HTF zone, the stronger it is. Full overlap (execution zone inside the HTF zone) is the strongest.
4. **Coinciding zone priority (p37).** An execution zone that coincides with an HTF zone beats one with a higher score that doesn't. ✱
5. **Refined zone (p37).** If the HTF zone is large, take the execution zone from inside it (the lower-TF zone within it).
6. **Target (p37).**
   - The default is 1:2 risk-reward.
   - If an opposing ITF zone (supply for a demand trade) sits before or near the 1:2 target, the target becomes that zone's proximal. This is the "our target" line in the diagram ✱.
   - Page 33's earlier note, that the ETF distal shouldn't pass the HTF distal, still applies.

# Part C: Code changes

This replaces the earlier scoring function. The p26/p20-22 quality factors from before (closing strength, range break, distribution grade) can stay as a tie-breaker.

```python
def trade_score(z, ltf_zones=None):
    s = 0.0

    # 1. freshness (p35)
    s += {0: 3.0, 1: 1.5}.get(z.times_tested, 0.0)

    # 2. strength (p35)
    if z.n_exciting_legouts >= 2:      s += 2
    elif z.legout_has_gap:             s += 2
    else:                              s += 1

    # 3. time at base (p35)
    nb = len(z.base)
    if nb == 0:
        s += 2          # no base: flat 2 (or re-check on lower TF first) ✱
    elif nb <= 3:       s += 2
    elif nb <= 5:       s += 1
    # >5 -> 0
    return s                                    # max 7
```

**Overlap and priority**

```python
def overlap_grade(ez, htf_zones):
    # 3 = inside HTF zone, 2 = partial overlap, 1 = within 1 ATR (near), 0 = none
    best = 0
    for h in htf_zones:
        if ez.type != h.type: continue
        lo, hi = max(ez.low, h.low), min(ez.high, h.high)
        if hi >= lo and ez.low >= h.low and ez.high <= h.high:   best = max(best, 3)
        elif hi >= lo:                                           best = max(best, 2)
        elif min(abs(ez.low - h.high), abs(ez.high - h.low)) <= NEAR_ATR * atr:
            best = max(best, 1)
    return best

def pick_execution_zone(etf_zones, htf_zones):
    # p37: coinciding zone first, then trade score
    return max(etf_zones,
               key=lambda z: (overlap_grade(z, htf_zones) >= 2,   # coinciding
                              trade_score(z),
                              overlap_grade(z, htf_zones)))
```

**Refined zone and target**

```python
def refine_with_ltf(htf_zone, ltf_zones):
    # p37: take the best zone inside the HTF zone
    inside = [z for z in ltf_zones if z.type == htf_zone.type and inside_zone(z, htf_zone)]
    return max(inside, key=trade_score, default=htf_zone)

RR = 2.0
def target(entry, stop, side, itf_zones):
    t = entry + RR * (entry - stop) if side == "BUY" else entry - RR * (stop - entry)
    opp = [z for z in itf_zones
           if z.type == ("supply" if side == "BUY" else "demand") and z.fresh]
    # nearest opposing zone ahead of entry
    ahead = [z for z in opp if (z.prox > entry if side == "BUY" else z.prox < entry)]
    if ahead:
        z = min(ahead, key=lambda z: abs(z.prox - entry))
        return z.prox      # p37 ✱ (alternative: min(t, z.prox) to exit before it)
    return t
```

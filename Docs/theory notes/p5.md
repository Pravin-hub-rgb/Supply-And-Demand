# Part B: Theory and rules

**New rules from these pages**

1. **Three TFs per trade (p30-31).** Each trade type uses an HTF, an ITF and an LTF.
   - HTF = location (where price sits between zones).
   - ITF = trend.
   - LTF = execution (the entry zone).
   - Trade types: HIT (intraday), DIT (intraday), WIT, MIT and QIT (positional).
2. **Trend filter (p30).** Use a 50 SMA on the ITF. Compare today's MA value with its value 7 candles back, counting the current candle.
   - Higher = uptrend (quadrant I).
   - Lower = downtrend (quadrant II).
   - Flat = sideways.
   - Different TFs can disagree, so each one is judged on its own.
3. **Location (p32).** On the HTF, find the nearest fresh demand zone and the nearest fresh supply zone. Divide the gap between their proximal lines into three equal bands: low on the curve (near demand), equilibrium (middle), high on the curve (near supply). Price inside a zone counts as very low or very high.
4. **Action table (p33):**

   | CMP location | Action |
   |---|---|
   | very low | definitely buy |
   | low | buy |
   | equilibrium | follow the trend |
   | high | sell |
   | very high | definitely sell |

   Sideways trend = ignore.
5. **Quality tolerance (p32).** The HTF zones that define location can be weaker or slightly tested. The execution-TF zone gets no compromise: it must be fully fresh and pass all the quality rules from the earlier pages.
6. **Execution-zone bounds (p33).** The ETF demand zone should not go below the HTF demand's distal line, and the ETF supply zone should not go above the HTF supply's distal line. ✱
7. **Single-zone case (p33).** If only a demand or only a supply zone exists at the location, treat the location as equilibrium and follow the ITF trend. ✱
8. **Multiple ITF zones (p34).** Pick the strongest one, using the scoring from the earlier pages.
9. **Trend change before entry (p34).** Wait. If the trend has changed by the time of entry, drop the trade. ✱
10. **HOC/VHOC (p34).** I haven't implemented this, because I don't know what the terms mean.

**My reading of the unclear parts ✱**

# Part C: Code changes

```python
TF_SETS = {  # (HTF, ITF, LTF)
    "HIT": ("75m", "15m", "5m"),     # 60m also allowed for HTF, 3m for LTF
    "DIT": ("D",   "75m", "15m"),
    "WIT": ("W",   "D",   "125m"),   # LTF options: 125/75/60/240m
    "MIT": ("M",   "W",   "D"),
    "QIT": ("Q",   "M",   "W"),
}
SMA_N, K        = 50, 7          # 7 candles including current
FLAT_ATR        = 0.15           # |MA change| below this (in ATR) = sideways (tune)
STRICT_TREND    = True           # p30: demand buys only in uptrend

# --- trend (p30): which quadrant is the MA in?
def trend(close, atr):
    s = sma(close, SMA_N)
    delta = s[-1] - s[-K]        # current vs 6 bars back
    if abs(delta) <= FLAT_ATR * atr: return "sideways"
    return "up" if delta > 0 else "down"

# --- location (p32): thirds between proximal lines
def location(cmp, dz, sz):
    if cmp <= dz.prox: return "very_low"       # inside/below demand zone
    if cmp >= sz.prox: return "very_high"      # inside/above supply zone
    third = (sz.prox - dz.prox) / 3
    if cmp < dz.prox + third:   return "low"
    if cmp > sz.prox - third:   return "high"
    return "equilibrium"

# --- action (p33)
def decide(loc, trend_itf):
    if trend_itf == "sideways": return None            # ignore
    if loc == "equilibrium":
        return "BUY" if trend_itf == "up" else "SELL"
    side = "BUY" if loc in ("low", "very_low") else "SELL"
    if STRICT_TREND and ((side == "BUY") != (trend_itf == "up")):
        return None                                    # p30: only with trend
    return side
```

```python
def find_trade(sym, mode):
    htf, itf, ltf = TF_SETS[mode]

    # 1. HTF location: nearest FRESH zones, quality may be relaxed (p32)
    dz = nearest_fresh(zones(sym, htf), "demand", cmp, min_score=LOW_Q)
    sz = nearest_fresh(zones(sym, htf), "supply", cmp, min_score=LOW_Q)
    if dz and sz:   loc = location(cmp, dz, sz)
    elif dz or sz:  loc = "equilibrium"                # p33 single-zone case ✱
    else:           return None

    # 2. ITF trend
    tr = trend(closes(sym, itf), atr(sym, itf))
    side = decide(loc, tr)
    if side is None: return None

    # 3. ITF: strongest zone in the trade direction (p34)
    itf_zones = [z for z in zones(sym, itf) if z.fresh and z.type == want(side)]
    z_itf = max(itf_zones, key=score, default=None)

    # 4. ETF: NO quality compromise (p32), bounded by HTF distal (p33)
    etf = [z for z in zones(sym, ltf) if z.fresh and z.score >= HIGH_Q
           and within_htf_bounds(z, dz, sz)]
    return best_entry(etf, z_itf, side)

def within_htf_bounds(z, dz, sz):
    if z.type == "demand": return dz is None or z.dist >= dz.dist   # ✱
    return sz is None or z.dist <= sz.dist

# 5. trend-change gate (p34): re-run before order is sent
def entry_still_valid(setup):
    return trend(closes(setup.sym, setup.itf), atr(...)) == setup.trend
```

# Part B: Theory and Rules Summary

1. **Dynamic Support & Resistance via 20 EMA (p52):**
* In a trending market, **20 EMA below price** acts as Dynamic Support.


* **20 EMA above price** acts as Dynamic Resistance.


* Must be mapped top-down: $12\text{M} \rightarrow \text{Quarterly} \rightarrow \text{Monthly} \rightarrow \text{Weekly} \rightarrow \text{Daily}$.


* Entry can be adjusted to sit slightly above the 20 EMA line when confluent with a zone.




2. **Quarterly 20 EMA Bounce & Non-Coinciding Zones (p53):**
* If price touches/approaches the **Quarterly 20 EMA**, strong same-day recovery is expected.


* At this specific location, even **non-coinciding execution zones are valid for trade execution**.




3. **Advance Trend Analysis (ATA) Rules (p53):**
* **Downtrend Transitions:**
* 1st Supply Zone broken $\rightarrow$ Trend becomes **SIDEWAYS / RANGING**.


* 2nd Supply Zone broken $\rightarrow$ Trend turns **UPTREND**.




* **Uptrend Transitions:**
* 1st Demand Zone broken $\rightarrow$ Trend becomes **SIDEWAYS**.


* 2nd Demand Zone broken (consecutively) $\rightarrow$ Trend turns **DOWNTREND**.




* **Zone Breach Definition:** A zone is considered broken **ONLY if price closes beyond the zone** (above supply / below demand). Newly formed zones that get broken also count towards this tally.




4. **ATA vs. Moving Averages / Conventional Analysis (p53 & p54):**
* If a 50 SMA signals an uptrend, but Advance Trend Analysis signals a downtrend, **ATA takes absolute priority**.


* Conventional analysis uses peak-to-peak end points (higher highs / lower lows), missing early moves. ATA tracks mid-range zone breaks, catching trends 1–2 trades earlier.

```python
# Day 13: Advance Trend Analysis (ATA) & 20 EMA Integration Engine

from enum import Enum
from typing import List, Dict, Tuple

class TrendState(Enum):
    UPTREND = "UPTREND"
    SIDEWAYS = "SIDEWAYS"
    DOWNTREND = "DOWNTREND"

class AdvanceTrendAnalyzer:
    def __init__(self):
        self.trend_state = TrendState.SIDEWAYS
        self.broken_supply_count = 0
        self.broken_demand_count = 0

    def evaluate_zone_break(self, candle_close: float, zone: Dict) -> bool:
        """
        p53 rule: A zone is broken ONLY if candle closes strictly beyond its boundary.
        """
        if zone['type'] == 'SUPPLY' and candle_close > zone['high']:
            return True
        elif zone['type'] == 'DEMAND' and candle_close < zone['low']:
            return True
        return False

    def update_trend(self, current_close: float, active_zones: List[Dict]) -> TrendState:
        """
        p53 rule: 
        Downtrend -> Break 1 SZ -> Sideways -> Break 2nd SZ -> Uptrend.
        Uptrend -> Break 1 DZ -> Sideways -> Break 2nd DZ -> Downtrend.
        """
        for zone in active_zones:
            if not zone.get('is_broken', False) and self.evaluate_zone_break(current_close, zone):
                zone['is_broken'] = True
                
                if zone['type'] == 'SUPPLY':
                    self.broken_demand_count = 0  # Reset opposite counter
                    self.broken_supply_count += 1
                    if self.broken_supply_count == 1:
                        self.trend_state = TrendState.SIDEWAYS
                    elif self.broken_supply_count >= 2:
                        self.trend_state = TrendState.UPTREND
                        
                elif zone['type'] == 'DEMAND':
                    self.broken_supply_count = 0  # Reset opposite counter
                    self.broken_demand_count += 1
                    if self.broken_demand_count == 1:
                        self.trend_state = TrendState.SIDEWAYS
                    elif self.broken_demand_count >= 2:
                        self.trend_state = TrendState.DOWNTREND

        return self.trend_state

def get_final_trend_direction(ata_trend: TrendState, sma_50_direction: str) -> TrendState:
    """
    p53 rule: If 50 SMA suggests uptrend but ATA suggests downtrend,
    ATA ALWAYS overrides the SMA.
    """
    return ata_trend  # Advance Trend Analysis takes strict priority over 50 SMA

def evaluate_quarterly_ema20_bounce(price: float, q_ema20: float, etf_zone_coincides: bool) -> Tuple[bool, str]:
    """
    p53 rule: Near Quarterly 20 EMA, non-coinciding execution zones are VALID to trade.
    """
    buffer = q_ema20 * 0.01  # 1% proximity threshold
    near_quarterly_ema20 = abs(price - q_ema20) <= buffer
    
    if near_quarterly_ema20:
        if not etf_zone_coincides:
            return True, "EXECUTE: Non-coinciding zone allowed near Quarterly 20 EMA!"
    return False, "STANDARD_RULES_APPLY"

```

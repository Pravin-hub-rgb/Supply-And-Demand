# Part B: Theory and Rules Summary

1. **Sector Analysis as an Extra Score Booster (p61):** Sector alignment adds a **+2 Trade Score**. It helps navigate high-panic market conditions by identifying systemic institutional flows.


2. **Weightage and Index Correlation (p61 & p62):**
* Heavyweights like HDFC Bank (11% in Nifty 50) and ICICI Bank dominate Financial Services and can drive Nifty/Bank Nifty single-handedly if moving 4-5%.


* Highly weighted stocks track their respective sector indices almost identically.




3. **Sector Support Confluence (p64):** If a stock is consolidating above a Higher Timeframe Demand Zone *and* its parent sector touches a Demand Zone, the probability of a successful breakout jumps to **99%**.


4. **Conservative vs. Aggressive Rules (p66):** Beginners must strictly remain **Conservative** (taking only coinciding levels with 80%+ accuracy, sector backing, and 20 EMA support) until turning professional. Aggressive entries are reserved for non-coinciding levels or counter-trend moves only under strict confirmation rules.


5. **Psychology & Risk Control (p67):**
* Cultivate a trader mindset focused on **looking for reasons to reject trades**, not reasons to force them.


* Never take long trades on lower timeframes if the Higher Timeframe (Quarterly) is sitting inside an active Supply Zone.

# Pages 61-67: Sector Analysis Confluence & Master Trade Filter Engine

from typing import Dict, List, Tuple

def evaluate_sector_confluence(stock_data: Dict, sector_data: Dict) -> Tuple[int, str]:
    """
    p61 & p64 rule: Check if stock has sector support. 
    Adds +2 score and checks for the 99% breakout confluence pattern.
    """
    score_boost = 0
    note = "NO_SECTOR_SUPPORT"
    
    stock_at_dz = stock_data.get('at_htf_dz', False)
    stock_consolidating = stock_data.get('is_consolidating', False)
    sector_at_dz = sector_data.get('at_sector_dz', False)
    
    if sector_at_dz:
        score_boost += 2.0  # p61: Sector analysis grants +2 trade score
        note = "SECTOR_SUPPORT_ACTIVE"
        
        if stock_at_dz and stock_consolidating:
            return score_boost, "HIGH_CONFLUENCE_99_PCT_BREAKOUT"
            
    return score_boost, note

def validate_master_trade_execution(stock_data: Dict, trader_experience: str) -> Tuple[bool, str]:
    """
    p66 & p67 rules: 
    1. Enforce conservative restrictions for beginners.
    2. Block long trades if Quarterly TF is inside a Supply Zone.
    """
    # Rule 1: Quarterly Supply Zone Block (p67)
    if stock_data.get('quarterly_tf_in_supply', False) and stock_data.get('trade_direction') == 'LONG':
        return False, "BLOCKED: Stock is in Quarterly Supply Zone. No long trades allowed!"
        
    # Rule 2: Beginner Conservative Enforcement (p66)
    is_coinciding = stock_data.get('is_coinciding', False)
    has_sector_support = stock_data.get('has_sector_support', False)
    
    if trader_experience == "BEGINNER" and not (is_coinciding and has_sector_support):
        return False, "REJECT (BEGINNER RULE): Beginners must only trade coinciding levels with sector support."
        
    return True, "TRADE_APPROVED"

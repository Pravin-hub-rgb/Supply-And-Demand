# Part B: Theory and Rules Summary

1. **Level Over the Level (LOTL) Range Management (p76):**
* When multiple demand/supply zones stack closely on the execution timeframe, **place entry at the midpoint between the areas**, and set the Stop Loss **below the distal line of the lowest zone**.


* If price reacts to the upper zone and picks up pending orders, the entire stacked zone area is considered **tested** and should subsequently be ignored.


* For 3 stacked zones, club the middle two zones together for execution.




2. **Trap Levels (p77):**
* Occurs when a recent zone fails (SL hit) and price taps into a prior normal zone, creating a retail trap (Bull/Bear traps) where conventional retail analysts make entry mistakes.


* Entry is placed at the upper zone with the Stop Loss positioned near the midpoint of the lower demand zone.




3. **Indicator Confluence: Stochastic RSI (p78):**
* All conventional patterns originate from underlying supply and demand mechanics.


* Stochastic RSI is a lagging indicator ($>80$ sell, $<20$ buy). It acts as an **auxiliary score booster** when an oversold/overbought reading coincides cleanly with a core Supply/Demand zone entry.




4. **Intraday Trading Rules & GTF Journey Structure (p79):**
* **Part-time traders** should avoid intraday trading.


* **Full-time traders** can execute intraday setups (DIT, MIT) by aligning lower timeframes strictly in the direction of Higher Timeframe (HTF) demand/supply flows, provided the execution zone has demonstrated achievement. Intraday consistency requires at least 6 months of dedicated screen-time mastery.

from typing import Dict, List, Tuple

def handle_level_over_level_stack(stacked_zones: List[Dict]) -> Tuple[float, float, str]:
    """
    p76 rule: When multiple execution zones stack on top of each other (LOTL),
    place entry at the midpoint of the outer boundaries and SL below the lowest distal line.
    """
    if not stacked_zones:
        return 0.0, 0.0, "NO_STACKED_ZONES"
        
    lowest_zone = min(stacked_zones, key=lambda z: z['low'])
    highest_zone = max(stacked_zones, key=lambda z: z['high'])
    
    # Entry at midpoint of the entire stacked range
    entry_midpoint = (highest_zone['high'] + lowest_zone['low']) / 2.0
    
    # Stop loss below the distal line of the lowest zone with buffer
    stop_loss = lowest_zone['low'] - (lowest_zone['high'] - lowest_zone['low']) * 0.1
    
    note = "LOTL_3_ZONE_CLUBBED" if len(stacked_zones) >= 3 else "LOTL_2_ZONE_STANDARD"
    return entry_midpoint, stop_loss, note

def evaluate_stochastic_rsi_confluence(zone_type: str, stoch_k: float) -> Tuple[float, str]:
    """
    p78 rule: Stochastic RSI acts as an extra trade score helper.
    Oversold (< 20) adds score for Demand zones; Overbought (> 80) adds score for Supply zones.
    """
    score_boost = 0.0
    note = "STOCHASTIC_NEUTRAL"
    
    if zone_type == 'DEMAND' and stoch_k <= 20.0:
        score_boost = 1.0
        note = "STOCHASTIC_OVERSOLD_DEMAND_BOOST"
    elif zone_type == 'SUPPLY' and stoch_k >= 80.0:
        score_boost = 1.0
        note = "STOCHASTIC_OVERBOUGHT_SUPPLY_BOOST"
        
    return score_boost, note

# Pages 80-86: Master Trade Scoring Engine & Position Management Rules

from typing import Dict, List, Tuple

def calculate_master_trade_score(trade_parameters: Dict) -> Tuple[float, str]:
    """
    p80 & p86 rule: Computes the complete Master Trade Score out of 20.
    Core components: Freshness (3), Strength (2), Time at Base (2).
    Extra boosters: Sector (2), EMA20 (1), Crossover (1), Gaps (1), Candlesticks (1), StochRSI (1).
    Discipline: Mandatory check (6 points or zero/disqualified if violated).
    """
    if not trade_parameters.get('has_discipline', True):
        return 0.0, "DISQUALIFIED: Discipline rule violated. All scores void."
        
    score = 0.0
    
    # Core Zone Metrics
    score += 3.0 if trade_parameters.get('is_fresh', False) else 0.0
    score += 2.0 if trade_parameters.get('has_strength', False) else 0.0
    score += 2.0 if trade_parameters.get('has_good_time_at_base', False) else 0.0
    
    # Extra Confluence Boosters
    score += 2.0 if trade_parameters.get('has_sector_support', False) else 0.0
    score += 1.0 if trade_parameters.get('has_ema20_confluence', False) else 0.0
    score += 1.0 if trade_parameters.get('has_ma_crossover', False) else 0.0
    score += 1.0 if trade_parameters.get('has_valid_gap', False) else 0.0
    score += 1.0 if trade_parameters.get('has_candlestick_pattern', False) else 0.0
    score += 1.0 if trade_parameters.get('has_stoch_rsi_confluence', False) else 0.0
    
    # Discipline Weight
    score += 6.0  # Maintained discipline points
    
    rating = "HIGH_CONVICTION_SETUP" if score >= 14 else "MODERATE_SETUP"
    return score, rating

def evaluate_stock_eligibility(stock_info: Dict) -> Tuple[bool, str]:
    """
    p83 rule: Exclude newly listed stocks (< 3 years old) or circuit-trapped stocks.
    """
    listing_age_years = stock_info.get('listing_age_years', 5.0)
    has_circuit_traps = stock_info.get('has_frequent_circuits', False)
    
    if listing_age_years < 3.0:
        return False, "REJECT: Stock listed less than 3 years ago."
    if has_circuit_traps:
        return False, "REJECT: Stock suffers from continuous upper/lower circuit locks."
        
    return True, "ELIGIBLE_FOR_WATCHLIST"

def manage_position_bookings(current_tf_zone: str, price_near_q_sz: bool, all_tfs_bullish: bool) -> str:
    """
    p38 (Page 83) rule: 
    - Book 50% at W/M SZ, 100% at Quarterly SZ.
    - If all TFs are bullish into Quarterly SZ, hold partial quantity for potential breakout.
    """
    if current_tf_zone in ['WEEKLY_SZ', 'MONTHLY_SZ']:
        return "BOOK_50_PERCENT_QUANTITY"
    elif current_tf_zone == 'QUARTERLY_SZ':
        if all_tfs_bullish:
            return "HOLD_PARTIAL_QUANTITY_POTENTIAL_BREAKOUT"
        return "BOOK_100_PERCENT_QUANTITY"
        
    return "TRAIL_POSITION"

# Part B: Theory and rules

**New rules from these pages**

1. **Closing strength (p20).** Compare the legout's close with the open of the first legin candle, which is where the selling started.
   - Close inside the legin body = weak.
   - Close at about the legin open = strong.
   - Close beyond the legin open = **more strong**.
2. **Zone strength from structure (p21-22).** A demand zone is stronger if the legout breaks the previous swing high (range break) or breaks a nearby supply zone. A demand zone that broke neither is weak (the ✗ zone). Supply is the mirror: it breaks a previous swing low or a nearby demand zone.
3. **Gap rule (p22).** A significant gap between the legin and the first base means buying already happened pre-market.
   - Mark the zone on the **first base candle** only.
   - If the 2nd base also opens above the legin, the zone is stronger.
4. **Base colour priority (p23).**
   - Demand: a green 2nd base is better.
   - Supply: a red 2nd base is better.
   - It is a priority only, not a requirement.
5. **Two-level zones (p23-25).** When a second base forms and an exciting candle follows, there are two zones:
   - **Aggressive** = the one nearest the exciting candle (DZ2 for demand, the lower base for supply).
   - **Conservative** = the farther one (DZ1 for demand, the upper base for supply).
   - Price reacts from the aggressive one if it comes down normally. If it comes down hard, it breaks the aggressive one and reacts from the conservative one.
6. **Rally-Base-Rally and Drop-Base-Drop (p24-25)** are valid continuation patterns, with the same rules.
7. **Distribution of price (p26).** Ranking after the base: **Best** = one or two big candles, **Better** = a few medium candles, **Good** = many small candles. A spread of small candles on a lower TF may be a single exciting candle on a higher TF.
8. **Origin marking (p27).** This replaces "mark the whole base cluster" for multi-base zones.
   - Mark only the base candle the move originated from (the lowest for demand, the highest for supply). The whole cluster only made the stop loss unnecessarily large.
   - Lines: aggressive entry (top line), conservative entry (middle line), stop loss at the origin candle's far wick.
9. **Garbage area (p28).** A cluster of candles that includes exciting candles but produces no significant move. It is not treated as a real base.
10. **Untested vs tested (p28).** Price touching a zone with no good reaction does not count as a test. The zone stays alive.
11. **Explosive move (p29).** If the move is huge or reaches an all-time high, price may reverse from a higher intermediate level and never return to the origin zone.

# Part C: Code changes

```python
GAP_ATR      = 0.3    # "significant gap" (start value, tune it)
EXPLO_ATR    = 1.5    # exciting candle body / ATR
GARBAGE_MOVE = 1.0    # max net move of cluster (in ATR) to call it garbage
REACT_ATR    = 1.0    # min bounce (ATR) to count a zone as "tested"
SWING_LOOKBACK = 30

# --- 1. closing strength (p20): 0 weak, 1 strong, 2 more strong
def closing_strength(d, legin, legout):
    ref = open[legin[0]] if d else open[legin[0]]   # where selling/buying started
    c = close[legout[-1]]
    if d: return 2 if c > ref + EPS else (1 if c >= ref - 0.1*atr else 0)
    else: return 2 if c < ref - EPS else (1 if c <= ref + 0.1*atr else 0)

# --- 2. range / opposing-zone break (p21-22)
def broke_range(d, legout, i0):
    if d:
        prev_high = max(high[i0-SWING_LOOKBACK:i0])
        return max(close[k] for k in legout) > prev_high
    prev_low = min(low[i0-SWING_LOOKBACK:i0])
    return min(close[k] for k in legout) < prev_low

def broke_opposing_zone(d, legout, zones):
    # demand: legout closes above the distal of a fresh supply zone nearby
    opp = [z for z in zones if z.type == ("supply" if d else "demand") and z.fresh]
    lc = close[legout[-1]]
    return any((lc > z.dist) if d else (lc < z.dist) for z in opp)

# --- 3. gap rule (p22): returns True if zone should sit on first base only
def gap_base(d, legin, base):
    if not base: return False
    g = (low[base[0]] - high[legin[-1]]) if d else (low[legin[-1]] - high[base[0]])
    return g >= GAP_ATR * atr

def second_base_above_legin(d, legin, base):
    if len(base) < 2: return False
    return (open[base[1]] > top(legin[-1])) if d else (open[base[1]] < bot(legin[-1]))

# --- 8. origin marking (p27): lowest (demand) / highest (supply) base candle only
def mark_origin(d, base, legout):
    if gap_base(...) : o = base[0]                       # p22 gap rule
    else: o = min(base, key=lambda k: low[k]) if d else max(base, key=lambda k: high[k])
    prox_agg = max(top(k) for k in base) if d else min(bot(k) for k in base)  # ✱ aggressive entry
    prox_con = top(o) if d else bot(o)                   # conservative entry
    dist     = low[o] if d else high[o]                  # stop loss
    return prox_agg, prox_con, dist
```

# Part B: Theory and Rules Summary

1. **Zone Testing Criteria (p57):** A zone is officially considered **tested** only after a strong, clean price reaction occurs; if price just struggles inside it without a reaction, it remains untested.


2. **Aggressive vs. Confirmation Trading Rules (p57 & p58):**
* **Aggressive Entries:** Allowed if price is at All-Time Highs with no overhead supply, or if a clean sideways trend has a coinciding zone.


* **Confirmation Entries (90% Accuracy) Required:** Needed when trading without a coinciding zone, during deep pullbacks/downtrends (e.g., 40-50% drops), or at All-Time Lows where R2/Supply zones must break first with confirmation.




3. **The Core 3-Step Execution Workflow (p58 & p60):**
* **Step 1:** Multiple Timeframe Analysis (MTFA) to spot potential setups (QIT, MIT, WIT, DIT using full scores, good closing, and achievement).


* **Step 2:** Top-Down Approach ($Y \rightarrow HY \rightarrow Q \rightarrow M \rightarrow W \rightarrow D$) to check structural flow, context, and macro direction. Limit historical depth per timeframe (e.g., Yearly: 4-5 candles, Quarterly: 10-15 candles).


* **Step 3:** Confirmation Entry (especially vital for non-coinciding or counter-trend setups).




4. **Role of Indicators & ATA (p58):** Moving Average crossovers (Golden/Death) and Advance Trend Analysis (ATA) are strictly auxiliary **scoring tools and trend filters**—they are *not* independent entry generation triggers.

from typing import Dict, List, Tuple

def evaluate_zone_tested_status(zone: Dict, price_action_history: List[Dict]) -> bool:
    """
    p57 rule: A zone is only 'tested' once a strong reaction occurs.
    Struggling inside the zone does not qualify as a test.
    """
    has_strong_reaction = any(candle.get('is_strong_reaction', False) for candle in price_action_history)
    return has_strong_reaction

def determine_trade_execution_mode(is_at_ath: bool, is_coinciding: bool, drop_percentage: float) -> str:
    """
    p57 & p58 rules: Decide whether to take an 'AGGRESSIVE' trade or wait for 'CONFIRMATION'.
    """
    if is_at_ath and is_coinciding:
        return "AGGRESSIVE_ALLOWED"  # p57: ATH with no overhead supply / normal coinciding setup
    
    if drop_percentage >= 40.0 or not is_coinciding:
        return "CONFIRMATION_REQUIRED"  # p57/58: Non-coinciding or deep drawdown needs 90% accuracy confirmation
        
    return "CONSERVATIVE_STANDARD"

def master_trading_pipeline(stock_data: Dict, htf_zones: List[Dict]) -> Tuple[str, str]:
    """
    p58 & p60: Core 3-Step Process Implementation
    Step 1: MTFA Check (QIT/MIT/WIT/DIT score validation)
    Step 2: Top-Down Context Validation (checking macro flow)
    Step 3: Execution Mode (Aggressive vs Confirmation)
    """
    # Step 1: MTFA Validation
    mtfa_score = stock_data.get('mtfa_score', 0)
    has_achievement = stock_data.get('has_achievement', False)
    if mtfa_score < 3 or not has_achievement:
        return "REJECT", "Failed MTFA quality or achievement criteria."

    # Step 2: Top-Down Historical Depth Constraints Check (p59)
    yearly_candles_checked = stock_data.get('yearly_candles_count', 0)
    if yearly_candles_checked > 5:
        return "REJECT", "Top-down error: Too far back on Yearly chart (keep to 4-5 candles)."

    # Step 3: Determine Execution Mode
    mode = determine_trade_execution_mode(
        is_at_ath=stock_data.get('is_at_ath', False),
        is_coinciding=stock_data.get('is_coinciding', True),
        drop_percentage=stock_data.get('drawdown_pct', 0.0)
    )
    
    return "PASS", f"Execution Mode: {mode}"

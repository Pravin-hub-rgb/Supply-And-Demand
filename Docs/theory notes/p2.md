# Part B: Theory in one place

**Candles**
- **Exciting (strong):** body > wick (body over 50% of range), price movement significant, and bigger than the previous candles' range.
- **Base:** anything not exciting, small range, buyers and sellers fighting.

**Structure:** Legin (exactly 1 exciting candle) → Base (few small candles) → Legout (1 or more exciting candles, the same color).

| Pattern | Legin | Legout | Zone | Type |
|---|---|---|---|---|
| DBR | red | green | Demand | Reversal (stronger) |
| RBR | green | green | Demand | Continuation |
| RBD | green | red | Supply | Reversal (stronger) |
| DBD | red | red | Supply | Continuation |

**Quality (what makes a zone stronger):** reversal over continuation; more legout candles; legout takes price far from the base; clean, undisturbed base; fresh.

**Where to look:** demand zones are found *below* the current price (scan left and down), supply zones *above* it (scan left and up). Ignore the latest live candle.

**Freshness**
- *Fresh:* price hasn't come back near the zone.
- *Tested:* price comes very near or touches the zone and goes back, including a second legout candle touching it.
- Trade and mark fresh zones only.

**Zone lines**

| | Proximal | Distal |
|---|---|---|
| Demand | highest body of base | lowest wick of base |
| Supply | lowest body of base | highest wick of base |

- **Exception, legout (all 4 patterns):** demand distal = legout's low if it's below the base low. Supply distal = legout's high if it's above the base high.
- **Exception, legin (reversal patterns only, DBR and RBD):** demand distal = legin's low if lower than the base low. Supply distal = legin's high if higher than the base high.
- Why legin is reversal-only ✱: in RBR and DBD the legin naturally sits far below or above the base, and the notes only show the legin exception for reversals.

**Trade plan**
- Demand: entry slightly above proximal, stop slightly below distal, target 1:2.
- Supply: entry slightly below proximal, stop slightly above distal, target 1:2.
- Weekly time frame first.

# Part C: Logic you can code

```python
# params (tune these)
BODY_PCT   = 0.5      # teacher: body > wick
RANGE_MULT = 1.0      # exciting range vs prior-candle range / ATR
MAX_BASE   = 3        # base count: unclear in notes, adjust
NEAR_TOL   = 0.1      # "very near" = 10% of zone height (my guess)
ENTRY_GAP  = 0.05     # fraction of zone height
SL_GAP     = 0.05

def exciting(i):
    return body[i] / rng[i] > BODY_PCT and rng[i] >= RANGE_MULT * ref_range[i]

def color(i): return "G" if close[i] > open[i] else "R"

def find_zones(skip_last=True):
    zones = []
    last = n - 2 if skip_last else n - 1
    for i in range(last, 2, -1):
        if not exciting(i): continue
        # 1. walk back over a run of same-colored exciting candles
        lo_start = i
        while exciting(lo_start - 1) and color(lo_start - 1) == color(i):
            lo_start -= 1
        legout = range(lo_start, i + 1)
        # 2. base: 1..MAX_BASE non-exciting candles before first legout
        b_end = lo_start - 1
        b_start = b_end
        while not exciting(b_start - 1) and b_end - (b_start - 1) < MAX_BASE:
            b_start -= 1
        # 3. legin: one exciting candle just before the base
        legin = b_start - 1
        if not exciting(legin) or exciting(b_start): continue
        base = range(b_start, b_end + 1)

        ztype   = "demand" if color(i) == "G" else "supply"
        pattern = color(legin) + "B" + color(i)           # e.g. RBR
        reversal = color(legin) != color(i)

        # lines (body-to-wick)
        if ztype == "demand":
            prox = max(max(open[k], close[k]) for k in base)
            dist = min(low[k] for k in base)
            dist = min(dist, min(low[k] for k in legout))        # exception: legout
            if reversal: dist = min(dist, low[legin])             # exception: legin
        else:
            prox = min(min(open[k], close[k]) for k in base)
            dist = max(high[k] for k in base)
            dist = max(dist, max(high[k] for k in legout))
            if reversal: dist = max(dist, high[legin])

        # validity: legout must actually leave the base in the right direction
        if ztype == "demand" and close[lo_start] <= prox: continue
        if ztype == "supply" and close[lo_start] >= prox: continue

        # freshness: look at every candle after the FIRST legout candle
        h = abs(prox - dist); tol = NEAR_TOL * h
        tested = any(
            (low[k]  <= prox + tol) if ztype == "demand" else (high[k] >= prox - tol)
            for k in range(lo_start + 1, n)
        )
        # also: demand zone must be below current price, supply above
        if tested: continue
        zones.append(dict(type=ztype, pattern=pattern, reversal=reversal,
                          prox=prox, dist=dist, legout_count=len(legout),
                          base_count=len(base)))
    return zones

def trade(z):
    h = abs(z["prox"] - z["dist"])
    s = 1 if z["type"] == "demand" else -1
    entry = z["prox"] + s * ENTRY_GAP * h
    sl    = z["dist"] - s * SL_GAP * h
    target = entry + s * 2 * abs(entry - sl)      # 1:2
    return entry, sl, target
```

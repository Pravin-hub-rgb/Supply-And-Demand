# Part B: Theory and rules

**New rules from these pages**
1. **Fewer base candles = stronger zone.** A 1-candle base beats a 4-candle base because buyers won quickly.
2. **No-base zones are allowed** (legin directly followed by legout).
3. **No-base marking:**
   - Demand: proximal = the higher of the two candles' bottom prices (body bottoms), distal = the lowest wick of the two.
   - Supply: proximal = the lower of the two body tops, distal = the highest wick of the two.
4. **Validity of a no-base zone:** at least one of the two candles must have a wick on the zone side (a lower wick for demand, an upper wick for supply). If neither does, both sit at the "same level" and the zone is ignored.
5. **Two marking styles:**
   - **Body-to-wick** (default): proximal at the base body extreme, distal at the base wick extreme.
   - **Wick-to-wick**: proximal at the base's wick extreme as well. Used only when the legout is explosive and the base range is small, so the two styles give almost the same box. If the difference is huge, stay with body-to-wick.
6. **Multi-timeframe refinement:** if a higher TF zone has no base, look at the lower TF inside that period. If a base appears there, use the lower TF's proper marking.
7. **Timeframe strength:** monthly > weekly > daily. A lower TF zone (like 15m) is reliable only with higher TF support.
8. **Stacked zones:** when two zones sit above each other and the first breaks, price reacts from the next one.

# Part C: Code changes

Allow zero base candles in the finder. Use `base = []` when the legout directly follows the legin. Then replace the line-marking part with this:

```python
EPS = 1e-9
def top(k): return max(open[k], close[k])
def bot(k): return min(open[k], close[k])

def mark_zone(ztype, legin, base, legout, atr, legout_explosive):
    d = (ztype == "demand")

    if base:                                   # normal zone
        wick_hi = max(high[k] for k in base);  wick_lo = min(low[k] for k in base)
        body_hi = max(top(k) for k in base);   body_lo = min(bot(k) for k in base)
        if d:  bw, ww = (body_hi, wick_lo), (wick_hi, wick_lo)   # (proximal, distal)
        else:  bw, ww = (body_lo, wick_hi), (wick_lo, wick_hi)
        ww_height = abs(ww[0] - ww[1])
        use_ww = legout_explosive and ww_height <= WW_MAX_ATR * atr   # small base range
        prox, dist = ww if use_ww else bw

    else:                                      # no base: legin -> legout directly
        a, b = legin, legout[0]
        if d:
            if low[a] >= bot(a) - EPS and low[b] >= bot(b) - EPS:
                return None                    # neither has a lower wick -> skip
            prox = max(bot(a), bot(b));  dist = min(low[a], low[b])
        else:
            if high[a] <= top(a) + EPS and high[b] <= top(b) + EPS:
                return None
            prox = min(top(a), top(b));  dist = max(high[a], high[b])

    # exceptions from before (lowest/highest point of the three elements)
    if d:
        dist = min(dist, min(low[k] for k in legout))
        if reversal: dist = min(dist, low[legin])
    else:
        dist = max(dist, max(high[k] for k in legout))
        if reversal: dist = max(dist, high[legin])
    return prox, dist
```

# Part B: Theory and Rules Summary

1. **Top-Down Review Order (p48):** Systematic top-down scanning must progress through $12M \rightarrow 6M \rightarrow 3M \rightarrow 1M \rightarrow \text{Weekly}$ to identify the primary driving zone and recent price action. Tested zones help establish the current structural trajectory.


2. **Zone Strength Rule (p48):** A zone's quality is primarily judged by the quality of its **legout candle** (strong legout = strong zone).


3. **Core Philosophy on Indicators vs. Supply/Demand (p49):** Conventional Moving Average crossovers fail >50% of the time on their own. Supply and demand remain the foundational, universal root mechanics that cannot be replaced—indicators are only secondary scoring tools.


4. **EMA Crossover as Trade Score Boost (p50):**
* A **Golden Crossover (GCO)** inside a Demand Zone adds extra trade score.


* A **Death Crossover (DCO)** inside a Supply Zone adds extra trade score.




5. **MA Traveling Inside Zone (p50):** Even without an explicit crossover, if the 20 and 50 EMAs are smoothly traveling *through* the execution-timeframe zone, it awards additional trade score.


6. **Priority & SL Adjustments (p51):** Zone quality always holds the highest priority. If a GCO forms slightly below a Demand Zone, the Stop Loss (SL) can be adjusted slightly lower, but the primary zone entry framework remains strict.

# p48-51 additions: Moving Average Trend Filter, Crossovers, and Zone Scoring

import numpy as np
import pandas as pd

def calculate_emas(df: pd.DataFrame, short_window=20, long_window=50):
    """
    Calculates 20 and 50 EMAs on execution/intermediate timeframes.
    """
    df['EMA_20'] = df['close'].ewm(span=short_window, adjust=False).mean()
    df['EMA_50'] = df['close'].ewm(span=long_window, adjust=False).mean()
    return df

def check_ma_zone_interaction(zone, df_etf):
    """
    p50 rule: Evaluates if 20 & 50 EMA experience a crossover or 
    are traveling through the zone to add trade score.
    """
    zone_low = zone['low']
    zone_high = zone['high']
    
    # Get recent candles inside or touching the zone
    recent_data = df_etf.tail(5)
    ema_20 = recent_data['EMA_20'].iloc[-1]
    ema_50 = recent_data['EMA_50'].iloc[-1]
    prev_ema_20 = recent_data['EMA_20'].iloc[-2]
    prev_ema_50 = recent_data['EMA_50'].iloc[-2]
    
    # Check for Golden Crossover (GCO) or Death Crossover (DCO)
    gco = (prev_ema_20 <= prev_ema_50) and (ema_20 > ema_50)
    dco = (prev_ema_20 >= prev_ema_50) and (ema_20 < ema_50)
    
    # Check if MAs are traveling inside the zone bounds
    mas_inside_zone = all((zone_low <= e <= zone_high) for e in [ema_20, ema_50])
    
    score_boost = 0
    note = "OK"
    
    if zone['type'] == 'DEMAND':
        if gco and (zone_low <= ema_20 <= zone_high):
            score_boost += 1.5  # Extra trade score for GCO in demand
            note = "GCO_INSIDE_DEMAND"
        elif mas_inside_zone:
            score_boost += 1.0  # Extra trade score for MA traveling through zone
            note = "MAS_TRAVELING_THROUGH_DEMAND"
            
    elif zone['type'] == 'SUPPLY':
        if dco and (zone_low <= ema_20 <= zone_high):
            score_boost += 1.5  # Extra trade score for DCO in supply
            note = "DCO_INSIDE_SUPPLY"
        elif mas_inside_zone:
            score_boost += 1.0  
            note = "MAS_TRAVELING_THROUGH_SUPPLY"
            
    return score_boost, note

# Part B: Theory and Rules Summary

1. **Candlestick Patterns as Extra Score Boosters (p68–p70):**
* Candlestick patterns (Harami, Engulfing, Morning/Evening Star, Hammer, Shooting Star) are **secondary score boosters**, not standalone triggers.


* **Zone Confluence Mandate:** A candlestick pattern is **only valid when formed INSIDE a Demand or Supply Zone**. Outside of a zone, individual candlestick patterns carry zero weight.




2. **Gap Classifications (p71–p73):**
* **Real Gap vs. Fake Gap:** Real gaps occur when open price deviates from the prior close; fake gaps stem from computational/data errors.


* **Inside Gap vs. Outside Gap:** Inside gaps stay within the high-low range of the previous bar; Outside gaps open completely beyond the previous bar's high/low range.


* **Novice Gap:** A gap in the **same direction** as the prevailing trend (retail momentum chasers).


* **Pro Gap (Stronger):** A gap in the **opposite direction** of the prevailing trend or out of a consolidation base (institutional footprint).




3. **High Probability Execution TF Gap Applications (p73–p75):**
* **Rule 1 (Novice Gap INTO Zone):** Price gapping *into* a Demand Zone (downward gap into DZ) creates a high probability setup because the gap gets filled upon zone reaction.


* **Rule 2 (Pro Gap FROM Zone):** Price gapping *away/out of* a Demand Zone (upward gap out of DZ) signals extreme institutional demand and makes it a high probability zone.


* **Rule 3 (Novice Gap INTO a Pro Gap):** A novice gap opening into a pre-existing pro gap area creates a super high-probability reversal confluence.


* **Rule 4 (Window Gap / Modified Entry):** If a pro gap leaves a "window gap" just above a Demand Zone without fully touching the proximal line, entry can be adjusted to the gap high to prevent missing the move.

# Pages 68-75: Candlestick Pattern Zone Filter & Gap Classification Engine

from typing import Dict, List, Tuple
from enum import Enum

class GapType(Enum):
    NOVICE_INTO_ZONE = "NOVICE_GAP_INTO_ZONE"
    PRO_FROM_ZONE = "PRO_GAP_FROM_ZONE"
    NOVICE_INTO_PRO_GAP = "NOVICE_INTO_PRO_GAP"
    WINDOW_GAP_MODIFIED_ENTRY = "WINDOW_GAP_MODIFIED_ENTRY"
    STANDARD_GAP = "STANDARD_GAP"
    NONE = "NONE"

def check_candlestick_pattern_in_zone(candle_prev: Dict, candle_curr: Dict, zone: Dict) -> Tuple[float, str]:
    """
    p68-p70 rules: Evaluates Bullish/Bearish Harami & Engulfing.
    MUST form inside a valid Demand/Supply Zone to award extra trade score.
    """
    zone_low, zone_high = zone['low'], zone['high']
    curr_inside_zone = (zone_low <= candle_curr['close'] <= zone_high) or (zone_low <= candle_curr['open'] <= zone_high)
    
    if not curr_inside_zone:
        return 0.0, "REJECT_PATTERN: Candlestick pattern outside of zone carries 0 weight."
    
    # Check Bullish Engulfing
    is_bullish_engulfing = (
        candle_prev['close'] < candle_prev['open'] and  # Prev red
        candle_curr['close'] > candle_curr['open'] and  # Curr green
        candle_curr['close'] >= candle_prev['open'] and 
        candle_curr['open'] <= candle_prev['close']
    )
    
    # Check Bullish Harami
    is_bullish_harami = (
        candle_prev['close'] < candle_prev['open'] and
        candle_curr['close'] > candle_curr['open'] and
        candle_curr['high'] <= candle_prev['high'] and
        candle_curr['low'] >= candle_prev['low']
    )
    
    if is_bullish_engulfing or is_bullish_harami:
        return 1.0, f"EXTRA_SCORE: Valid pattern ({'Engulfing' if is_bullish_engulfing else 'Harami'}) INSIDE Zone."
        
    return 0.0, "NO_PATTERN_DETECTED"

def evaluate_gap_mechanics(prev_candle: Dict, curr_candle: Dict, zone: Dict) -> Tuple[GapType, float, str]:
    """
    p71-p75 rules: Classify Real Gaps (Inside/Outside, Novice/Pro) 
    and apply high-probability zone scoring rules.
    """
    prev_high, prev_low = prev_candle['high'], prev_candle['low']
    prev_close = prev_candle['close']
    curr_open = curr_candle['open']
    
    is_gap_up = curr_open > prev_high
    is_gap_down = curr_open < prev_low
    
    if not (is_gap_up or is_gap_down):
        return GapType.NONE, 0.0, "No Real Outside Gap detected."

    score_boost = 0.0
    zone_low, zone_high = zone['low'], zone['high']
    
    # Rule 1: Novice Gap INTO Demand Zone (p73) - Gap down into DZ
    if zone['type'] == 'DEMAND' and is_gap_down and (zone_low <= curr_open <= zone_high):
        score_boost = 2.0
        return GapType.NOVICE_INTO_ZONE, score_boost, "HIGH_PROBABILITY: Novice Gap into Demand Zone."

    # Rule 2: Pro Gap FROM Demand Zone (p74) - Gap up away from DZ
    if zone['type'] == 'DEMAND' and is_gap_up and (prev_low <= zone_high):
        score_boost = 2.5
        return GapType.PRO_FROM_ZONE, score_boost, "HIGH_PROBABILITY: Pro Gap moving away from Demand Zone."

    # Rule 4: Window Gap / Entry Modification (p75)
    if zone['type'] == 'DEMAND' and is_gap_up and (curr_open > zone_high):
        gap_buffer = curr_open - zone_high
        if gap_buffer <= (zone_high - zone_low) * 0.5:
            return GapType.WINDOW_GAP_MODIFIED_ENTRY, 1.5, f"MODIFY_ENTRY: Set entry to gap floor ({curr_open}) due to Window Gap."

    return GapType.STANDARD_GAP, 0.5, "Standard Real Gap detected."
